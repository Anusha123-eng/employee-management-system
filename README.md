# Employee Management System

A full-stack Employee Management System developed using React.js and Spring Boot.

## Technologies Used

### Frontend
- React.js
- JavaScript
- HTML
- CSS
- Bootstrap
- Axios
- React Router
- Vite

### Backend
- Java
- Spring Boot
- Spring REST API
- Spring Data JPA
- Hibernate
- Maven

### Database
- MySQL

### Tools
- IntelliJ IDEA
- Visual Studio Code
- Postman
- Git
- GitHub

## Features

- Add Employee
- View Employee List
- Update Employee
- Delete Employee
- Delete confirmation popup
- Form validation
